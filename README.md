# Finance System Backend

A Python-based finance tracking API built with **FastAPI**.  
Supports CRUD operations, filtering, summaries, and role-based access.

---

## 🚀 Setup

```bash
# Clone the repository
git clone <https://github.com/Ronnaak/finance-system-backend.git>
cd finance-backend

# Install dependencies
pip install -r requirements.txt

# Run the server
uvicorn app.main:app --reload
